## Descripció

Aquest projecte consisteix en l'anàlisi d'un conjunt de dades de videojocs de la plataforma Steam utilitzant Python i Jupyter Notebook.

Durant el projecte s'ha realitzat:

- Exploració de les dades.
- Detecció de valors nuls.
- Obtenció d'estadístiques descriptives.
- Visualització de dades mitjançant gràfics.
- Formulació de preguntes de recerca.
- Extracció de conclusions.

## Estructura del projecte

- `steam.csv` → Dataset analitzat.
- `analisi.ipynb` → Notebook amb el codi Python.
- `Informe.pdf` → Memòria amb els resultats de l'anàlisi.
- `README.md` → Informació general del projecte.

## Tecnologies utilitzades

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
